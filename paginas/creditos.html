Créditos y fuentes

Reconocemos las fuentes de información y los recursos utilizados para desarrollar ITACE DIGITAL 4.0.

Detrás de nuestro proyecto

Esta página reúne los créditos de las fuentes, imágenes, videos y herramientas que contribuyeron al desarrollo de nuestro sitio web escolar.

1. Información institucional

  • Sitio oficial del ITACE
  • Información del Plantel Reynosa, su oferta educativa y sus servicios, sujeta a verificación en las fuentes institucionales.

2. Fotografías e imágenes

  • Fotografías de instalaciones, actividades y proyectos incorporadas al sitio.
  • Los créditos específicos deben añadirse según el autor o la fuente de cada archivo.
  • Se deben respetar los permisos de uso y la privacidad de las personas fotografiadas.

3. Videos y material audiovisual

  • Videos y materiales audiovisuales utilizados en la sección de Identidad y Orgullo ITACE.
  • Completar con el título, autor o institución responsable y la fuente de cada video.
  • Verificar que se cuente con autorización para incorporar y publicar estos materiales.

4. Herramientas de desarrollo

  • HTML para la estructura de las páginas.
  • CSS para los estilos y el diseño adaptable.
  • JavaScript para las funciones interactivas.
  • Visual Studio Code como editor de código, si fue la herramienta utilizada.
  • Git y GitHub para el control de versiones, si se utilizaron.

5. Diseño y elaboración

  • Diseño visual con una paleta de colores vino, beige y dorado.
  • Organización de contenidos y elaboración de las páginas del proyecto.
  • Adaptación para computadoras, tabletas y teléfonos celulares.
