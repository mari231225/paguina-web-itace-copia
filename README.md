ITACE DIGITAL 4.0

ITACE Plantel Reynosa

Descripción

ITACE DIGITAL 4.0 es un sitio web informativo desarrollado para dar a conocer el Plantel Reynosa del Instituto Tamaulipeco de Capacitación para el Empleo (ITACE).

El proyecto reúne información institucional, oferta educativa, docentes, instalaciones y actividades escolares en una plataforma digital.

Objetivo

Crear un espacio digital accesible, organizado y adaptable a diferentes dispositivos para que estudiantes, aspirantes y visitantes conozcan más sobre el plantel.

Secciones del sitio

* Inicio
* Conócenos
* Oferta educativa
* Directorio docente
* Admisiones
* Eventos y noticias
* Galería
* Instalaciones
* Identidad institucional
* Vida estudiantil
* Proyectos estudiantiles
* Contacto
* Preguntas frecuentes

Tecnologías utilizadas

* HTML5
* CSS3
* JavaScript
* Git y GitHub

Características

* Diseño adaptable a dispositivos móviles.
* Navegación entre diferentes secciones.
* Directorio de docentes.
* Contenido multimedia.
* Información institucional y académica.

Autoría

Proyecto escolar desarrollado para ITACE Plantel Reynosa.

Estado del proyecto
